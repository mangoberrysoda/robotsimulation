1. Getting Started

1.1. Uploading a Map

The simulation requires an environment map to operate.

  • Custom Map: Click Choose File to upload any image. The simulation treats dark pixels (brightness < 160) as obstacles and light pixels as traversable space.
  • Default Map: Click Use Default to load the built-in obstacle map.

1.2. Placing Entities

Use the Placement section to select a tool:

  • Place Survivors: Click on the map to add survivors (Red dots). These are the targets the robots need to find.
  • Place Robots (Start): Click on the map to set the starting point for all robots. You can only have one starting point.
Tip You cannot place survivors or robots inside obstacles. If you try, the app will alert you.

2. Simulation Controls

2.1. Adjusting Robot Count

Use the Count slider (or type a number directly) to set how many robots will participate (1 to 20 agents).

2.2. Running the Simulation

  • Start/Stop: Click the Start button to begin. The button toggles to a red Stop state during execution.
  • Reset: Returns all robots to the starting point and clears the visited history. Placed survivors remain in position.
  • Clear All: Completely removes all survivors and the robot start point.

2.3. Speed & Performance

  • Speed (FPS): Controls rendering frequency. Higher values are smoother but more CPU-intensive.
  • Steps/Update: Increases simulation velocity by calculating multiple logic cycles per frame without affecting visual smoothness.

3. Sensor & Analytics

3.1. Sensor Configurations

  • Lidar Range/Angle: Defines the robot's visual field. Lidar is blocked by walls and other survivors.
  • Heat Radius: Detection range that ignores walls. Used for initial survivor "Location".

3.2. Live Stats Dashboard

  • Free Area: Total traversable map space based on obstacle layout.
  • Cleaned Area: Real-time progress percentage of explored space.
  • Mapped Points / Robot: Efficiency breakdown showing unique points contributed by each individual agent.

4. Completion & Feedback

The simulation automatically halts when:

  • 100% Coverage is achieved.
  • All robots have returned home after full exploration.
  • The move limit (10,000 steps) is reached.
Note Upon auto-stop, any remaining unvisited areas are highlighted in Bright Orange to identify missed zones.
